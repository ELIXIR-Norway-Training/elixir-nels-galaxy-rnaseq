# RNA-seq Analysis Using Galaxy

## Introduction

This tutorial introduces RNA-seq data analysis using Galaxy, a
web-based platform for reproducible bioinformatics workflows.

The session demonstrates how to process RNA-seq data, perform
quality control, map sequencing reads to a reference genome,
quantify gene expression, and identify differentially expressed
genes.

The demonstration follows the official Galaxy Training Network
(GTN) tutorial.

## 1. Galaxy Training Network Tutorial

### Reference-based RNA-Seq Data Analysis

**Official tutorial:**

[Galaxy Training Network GNT – Reference-based RNA-Seq Data Analysis](https://training.galaxyproject.org/training-material/topics/transcriptomics/tutorials/ref-based/tutorial.html)

**Tutorial information:**

- **Provider:** Galaxy Training Network (GTN)
- **Level:** Introductory
- **Organism:** *Drosophila melanogaster*
- **Analysis:** Differential gene expression using RNA-seq

> **Note:** During our course, we will demonstrate selected
> steps of this tutorial. Students are encouraged to complete
> the full tutorial independently.

# 2. Before Starting

To follow the demonstration:

1. Open [Galaxy Norway](https://usegalaxy.no/).
2. Log in to your Galaxy account.
3. Familiarize yourself with the Galaxy interface.
4. Open the [GTN RNA-seq tutorial](https://training.galaxyproject.org/training-material/topics/transcriptomics/tutorials/ref-based/tutorial.html).


# 3. Learning Outcomes

After completing the demonstration, participants should be
able to:

1. Navigate the Galaxy interface.
2. Import and manage sequencing datasets.
3. Understand the major steps of an RNA-seq workflow.
4. Recognize the main tools used for RNA-seq analysis.
5. Interpret the basic outputs of differential expression analysis.
6. Find and reuse Galaxy workflows and training materials.
